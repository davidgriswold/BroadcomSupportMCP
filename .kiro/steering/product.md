# Product

Broadcom Support MCP Server は、Broadcom Support Portal のナレッジベース記事を検索・取得する MCP (Model Context Protocol) サーバー。

VMware、Tanzu、Cybersecurity など Broadcom 製品群のドキュメントに、AIアシスタントからアクセスできるようにする。

## 提供ツール

- `search_documentation`: SearchUnify API 経由でナレッジベースを検索する
- `read_documentation`: 指定 URL の記事を取得し Markdown 形式で返す
